macOS Security Paths

High value paths, persistence locations, privacy controls and forensic artifacts on current macOS, with the commands to check them. Most protected paths need root plus Full Disk Access for Terminal.

macOS 27 Golden Gate111 entriesReviewed November 2026

Overview

Key facts about the current release and where the security relevant data lives.

Current releasemacOS Golden Gate 27.2.1 (November 2026). macOS 27 runs on Apple silicon only.
Support statusIn practice Apple patches the current release and the two before it: Tahoe 26.7.3 and Sequoia 15.8.3 still get security updates. Tahoe 26 is the last release for Intel Macs.
File systemAPFS. A signed, read-only system volume (SSV) mounted at / and a writable data volume at /System/Volumes/Data, joined by firmlinks.
Built-in security featuresSIP, SSV, Gatekeeper and notarization, XProtect and XProtect Remediator, TCC privacy controls, FileVault, Secure Enclave, Lockdown Mode, Background Task Management alerts.
Where logs liveUnified log in /private/var/db/diagnostics/ (read with log show), a few text logs in /var/log/, crash reports in DiagnosticReports.
Access modelRoot is not enough for most artifacts: TCC also blocks Terminal until it has Full Disk Access in System Settings, Privacy and Security.

Authorized use only: the offensive notes on this page are for Macs you own or have written permission to test.

Hardening Checklist

Baseline settings for personal and managed Macs.

  • Run a supported release and turn on automatic security updates. Plan to replace Intel Macs, which stop at Tahoe 26.
  • Keep FileVault on and escrow the recovery key in MDM, not on paper next to the Mac.
  • Leave SIP enabled and the system volume sealed. Never run day to day with Reduced Security.
  • Keep Gatekeeper on and only install notarized apps from known developers or the App Store.
  • Turn on the application firewall with stealth mode; add pf rules for servers.
  • Turn off Remote Login, Screen Sharing, Remote Management and File Sharing unless needed. If SSH is needed, allow keys only.
  • Review System Settings, General, Login Items and Extensions, and act on Background Task Management alerts.
  • Review Full Disk Access, Accessibility, Screen Recording and Input Monitoring grants regularly.
  • Use a standard account day to day and a separate admin account for changes.
  • Disable automatic login so /etc/kcpassword never exists.
  • Manage fleets with MDM using declarative device management; legacy MDM software update commands stopped working in the 27.0 releases.
  • Deploy an EDR built on Endpoint Security and forward unified log events to your SIEM.
  • Turn on Lockdown Mode for people at risk of targeted spyware.
  • Encrypt Time Machine backups and keep one copy offline.
