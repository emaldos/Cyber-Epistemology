System Files

iOS Security Reference

How to get data off an iPhone, which on-device files matter, and how to check a phone for spyware. On a stock iPhone you cannot browse these paths: you work from backups, sysdiagnose archives and full file system extractions.

iOS 2773 entriesReviewed November 2026
All systems Windows 11 Windows Server macOS iOS Android Ubuntu Server Kali Linux

Overview

Key facts about the current release and how its protections shape what you can collect.

Current releaseiOS and iPadOS 27.2.1 (November 2026). iOS 27 supports iPhone 11 and later.
Support statusiOS 26.7.3 and iOS 18.7.12 still received security fixes in November 2026. iPhone XS, XR and older are not supported by iOS 27.
File systemAPFS with a signed, read-only system volume and a data volume at /private/var. Every file is encrypted with a Data Protection class tied to the passcode.
Built-in security featuresSecure Enclave, Data Protection, code signing and sandboxing, BlastDoor, Lockdown Mode, Stolen Device Protection, USB Restricted Mode, inactivity reboot, Memory Integrity Enforcement on A19 and newer chips, Advanced Data Protection for iCloud.
Where logs liveUnified log in /private/var/db/diagnostics/, collected through a sysdiagnose or a paired Mac. Crash reports appear in Settings, Privacy and Security, Analytics and Improvements, Analytics Data.
Access realityOn-device paths below are only readable in a full file system extraction (commercial tools or a jailbreak). Backups and sysdiagnose give a large subset without either.

Lock state matters: after a restart the phone is in Before First Unlock (BFU) state and most data stays encrypted. Since iOS 18.1 a locked iPhone restarts itself after about 72 hours without unlock, which returns it to BFU. Acquire early and keep the device charged.

Spyware and reboots: most modern iOS exploit chains are not persistent and are lost on restart, so attackers reinfect. A daily restart is a cheap mitigation, and the infection traces live in logs and databases, not in startup items.

Hardening Checklist

Settings that block most real world attacks on iPhones.

  • Install updates as soon as they ship and turn on automatic updates and Background Security Improvements.
  • Use a six digit or longer alphanumeric passcode with Face ID or Touch ID.
  • Turn on Stolen Device Protection.
  • Turn on Lockdown Mode for journalists, activists, executives and anyone at risk of mercenary spyware.
  • Restart the phone regularly; it removes non persistent implants and returns data to the BFU state.
  • Review Settings, General, VPN and Device Management and remove unknown profiles.
  • Check Certificate Trust Settings for root certificates you did not add.
  • Use Safety Check (Settings, Privacy and Security) to review shared access, locations and paired devices.
  • Turn on Advanced Data Protection for iCloud where available, and keep a recovery key or contact.
  • Encrypt local backups and delete old backups from shared or old computers.
  • Use an Apple Account with two factor authentication and security keys.
  • Do not jailbreak production devices; it disables code signing and sandbox protections.
  • Save a sysdiagnose before major updates on high risk devices so logs are preserved for later checks.
