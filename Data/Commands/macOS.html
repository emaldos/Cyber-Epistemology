Shell Basics on macOS

zsh, Homebrew and the small Mac only tools that glue the terminal to the desktop.

Generic Unix commands: ls, grep, find, ps, ssh, pipes and scripting work the same way on a Mac and are covered on the Bash and Linux sheet, which also has a table of BSD versus GNU differences (sed -i '', stat -f, date -v). This page only lists what is specific to macOS.

Users and Permissions

macOS keeps accounts in Directory Services, not in /etc/passwd, so use dscl, dseditgroup and sysadminctl.

Defaults (Preferences)

Read and change app and system preferences stored as plists. Restart the app (or killall it) for most changes to apply.

CommandPurposeExample
defaults domainsEvery preference domain for the current userdefaults domains | tr ',' '\n' | less
defaults readAll settings of a domain, or one keydefaults read com.apple.dock autohide
defaults read -gGlobal settings, for example dark modedefaults read -g AppleInterfaceStyle
defaults write -boolShow hidden files in Finder (Cmd+Shift+. toggles it too)defaults write com.apple.finder AppleShowAllFiles -bool true && killall Finder
defaults write -stringSave screenshots to a folder of your choicedefaults write com.apple.screencapture location ~/Pictures/Screenshots
defaults write network storesStop Finder writing .DS_Store files on network sharesdefaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true
defaults deleteRemove a key to go back to the default valuedefaults delete com.apple.finder AppleShowAllFiles
defaults read system fileSystem wide preferences by path, for example the login windowdefaults read /Library/Preferences/com.apple.loginwindow

Note: settings delivered by an MDM profile live in /Library/Managed Preferences and override anything you write with defaults. Many security settings, such as FileVault or the firewall, are better checked with their own tools than with raw preference keys.

Authorization: run these checks only on Macs you own or are responsible for. Collect evidence (log archive, hashes, copies of suspicious plists) before you remove anything, and note that Terminal needs Full Disk Access for TCC, Time Machine and some log queries.

macOS 27 notes: Golden Gate runs on Apple silicon only, so macOS 26 Tahoe is the last release for Intel Macs. hdiutil is deprecated in favour of diskutil image, encrypted HFS+ is deprecated, and Rosetta is expected to be removed in macOS 28 except for some games.
