Permissions and Ownership

Modes, owners, ACLs, attributes, capabilities and SUID discovery.

r=4 w=2 x=1Add per digit: owner, group, others
600Private file, for example an SSH private key
644Readable by everyone, writable by owner
640Config readable by a service group
700 / 755Private directory / public directory or program
1777Sticky bit: anyone writes, only owners delete (like /tmp)

Tip: unexpected SUID binaries, capabilities such as cap_setuid and broad sudo -l entries are classic privilege escalation paths. Check each one against GTFOBins.

Script template

#!/usr/bin/env bash
set -euo pipefail
readonly scriptName="$(basename "$0")"
workDirectory="$(mktemp -d)"
trap 'rm -rf "$workDirectory"' EXIT
: > "$workDirectory/results.txt"
usage() {
echo "usage: $scriptName <host-file>" >&2
exit 1
}
checkHost() {
local host="$1"
if timeout 2 bash -c "< /dev/tcp/$host/22" 2>/dev/null; then
echo "$host: ssh open"
else
echo "$host: ssh closed"
fi
}
[[ $# -eq 1 && -f "$1" ]] || usage
while IFS= read -r host; do
[[ -z "$host" ]] && continue
checkHost "$host" | tee -a "$workDirectory/results.txt"
done < "$1"
echo "Checked $(wc -l < "$workDirectory/results.txt") hosts"
