Built-ins and Help

Get help, reuse history and set up the session.

CommandPurposeExample
helpList built-in commands with a one-line descriptionhelp

NAME /?Help for any tool. External tools such as robocopy only answer to /?robocopy /?

Keys: Tab completes paths, F7 shows a history list, F3 repeats the last command, Ctrl + C stops a running command.

From PowerShell: sc is an alias for Set-Content in Windows PowerShell 5.1, so type sc.exe. Use curl.exe in 5.1 too, because there curl means Invoke-WebRequest.

Text Search and Filters

find for literal strings, findstr for several words, phrases and a limited regex.

findstr syntax: there is no | alternation. Words separated by spaces are matched as OR, so "fail error" finds either word. Use /c:"literal phrase" for a phrase with spaces. The regex mode (/r) knows . * ^ $ [ ] and little else.

CommandPurposeExample
findLines that contain a literal string, case insensitivefind /i "error" app.log
find /cCount matching linesfind /c /i "failed" app.log
find /c /v ""Count all lines in a file, like wc -lfind /c /v "" app.log
find /vDrop lines that contain a stringtype app.log | find /v "DEBUG"
findstrLines that contain any of several wordsfindstr /i "fail error" *.log
findstr /c:Search for an exact phrase with spacesfindstr /i /c:"access denied" *.log
findstr /s /mRecursive search, print only the names of matching filesfindstr /s /i /m "password" *.config *.xml *.ini
findstr /rRegex with line numbers, here lines that start with ERROR and a digitfindstr /n /r /c:"^ERROR [0-9]" app.log
findstr /g:Take the search strings from a file, one per line, for example a list of IOCsfindstr /i /g:iocs.txt proxy.log
sortSort lines, reverse with /r, write with /osort /r names.txt /o sorted.txt
Remove duplicate linesCMD has no uniq. Call PowerShell for itpowershell -NoProfile -Command "Get-Content names.txt | Sort-Object -Unique"

WMIC is gone: use PowerShell CIM

Legacy: wmic was deprecated for years and is now removed from supported Windows 11 releases, without a Feature on Demand to add it back. WMI itself still works. Old scripts should call PowerShell with Get-CimInstance instead. Avoid Win32_Product: querying it is slow and triggers MSI consistency checks.

CommandPurposeExample
wmic os get caption,versionOS name and versionpowershell -NoProfile -Command "Get-CimInstance Win32_OperatingSystem | Select-Object Caption,Version,LastBootUpTime"
wmic process get name,commandlineProcesses with command lines and parent PIDpowershell -NoProfile -Command "Get-CimInstance Win32_Process | Select-Object Name,ProcessId,ParentProcessId,CommandLine"
wmic service get name,pathnameService binaries and accountspowershell -NoProfile -Command "Get-CimInstance Win32_Service | Select-Object Name,StartName,PathName"
wmic qfe listInstalled updatespowershell -NoProfile -Command "Get-HotFix | Sort-Object InstalledOn"
wmic bios get serialnumberDevice serial numberpowershell -NoProfile -Command "(Get-CimInstance Win32_BIOS).SerialNumber"
wmic logicaldisk get caption,freespaceDrives and free spacepowershell -NoProfile -Command "Get-CimInstance Win32_LogicalDisk | Select-Object DeviceID,FreeSpace,Size"
wmic product get nameInstalled applications, without Win32_Productwinget list

Template batch file

Delayed expansion, a loop that counts, a subroutine and a checked exit code. %date% and %time% depend on the regional format, so the log name is built in PowerShell.

@echo off
setlocal enabledelayedexpansion
cd /d "%~dp0"
for /f "delims=" %%a in ('powershell -NoProfile -Command "Get-Date -Format yyyyMMdd-HHmmss"') do set "STAMP=%%a"
set "LOG=%~dp0backup-%STAMP%.log"
set /a FILES=0
for %%f in (*.cfg) do (
    set /a FILES+=1
    call :log "Copying %%f as file !FILES!"
    copy /y "%%f" "D:\Backup\" >nul || goto :failed
)
robocopy "C:\Data" "D:\Backup\Data" /e /r:1 /w:1 >> "%LOG%" 2>&1
if errorlevel 8 goto :failed
call :log "Done, !FILES! config files copied"
exit /b 0
:failed
call :log "Backup failed with code %errorlevel%"
exit /b 1
:log
echo [%time%] %~1
echo [%time%] %~1 >> "%LOG%"
goto :eof
