Install Tool Sets and Keep Kali Current

A fresh Kali ships with a sensible default set. Metapackages add more, and a rolling release needs regular updates.

Authorized use only: the tools on this page are for systems you own or have written permission to test. Running them against anything else is likely a crime. Practice on a lab, a range or an intentionally vulnerable target.

Kali is a rolling release. Update it often so tool versions, signatures and wordlists stay current.
