Utilities

Everyday helpers for CTFs, assessments and incident response. Everything runs locally in your browser: nothing you paste here is uploaded, logged or sent anywhere, and the tools keep working offline.

Encode and Decode

Convert text to and from Base64, Base64URL, URL encoding, HTML entities, hex and binary. Text is handled as UTF-8, so accents, symbols and emoji survive the round trip.

Hash Generator

Hashes are calculated as you type. Text is hashed as UTF-8 bytes. SHA uses the browser Web Crypto API, MD5 is calculated in plain JavaScript.

MD5 and SHA-1 are broken for collision resistance. Never use any fast hash on its own to store passwords: use Argon2id, scrypt or bcrypt.

Hash Identifier

Paste a hash to see the likely types based on its length, character set and prefix, with the hashcat mode where one is well known. Identification is a best guess: many types share the same length, so try the most likely candidates first.

JWT Decoder

Paste a JSON Web Token to read its header and payload. Time claims are shown as UTC dates.

The signature is not verified. Decoding only reads the token, and anyone can create a token with any claims. Never trust a token because it decodes.

Subnet Calculator


Enter an IPv4 address in CIDR notation such as 10.10.10.0/24, or an address with a netmask such as 192.168.1.77 255.255.255.192.





































Timestamp Converter


Convert Unix time in seconds or milliseconds and Windows FILETIME (100 nanosecond intervals since 1601-01-01 UTC, used in NTFS, the registry and Active Directory) to dates, and dates back to timestamps.
