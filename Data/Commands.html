Run Commands Safely

  • Read a command before you paste it. Copy buttons copy exactly what is shown.
  • Test destructive commands (delete, format, registry, firewall) in a lab or VM first.
  • Prefer a normal user shell. Elevate only for the single command that needs it.
  • Only run offensive tools against systems you own or have written permission to test.
